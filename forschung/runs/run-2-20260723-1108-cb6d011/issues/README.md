# Issue-Artefakte

Die autoritative Run-1-gegen-Run-2-Matrix liegt bewusst im Run-Root:

- `../known-issues-comparison.csv` — 48 bekannte MF-Issues plus getrennte
  Run-2-Neufunde, jeweils mit zwölf Pflichtfeldern
- `../retest-matrix.md` — menschenlesbare Retestübersicht
- `../processed/issue-matrix-validation.json` — maschinenlesbares
  Vollständigkeits- und Statusgate

Einzelbelege werden nicht in diesen Ordner kopiert. Die Matrix verweist auf
die unveränderten Sessionlogs, Tests, Codepfade und Auswertungen, damit keine
zweite, potenziell abweichende Belegversion entsteht.

Aktueller Zwischenstand: 61 Vergleichspunkte, davon 48 Run-1-Issues und 13
Run-2-Neufunde. Zählung und Statusverteilung können sich bis zum finalen
Cloud- und Follow-up-Retest noch ändern.
